# Drafts for upstream

Reports ready to be read, corrected and posted by a person. None has been posted. Each says what
was measured and on what; anything not measured is marked as such.

- `webkit-software-gl-compositing.md`: WebKit Bugzilla, the cost of accelerated compositing on a
  software rasterizer and the missing fallback.
- `webkit-policy-never-blank-2.54.md`: WebKit Bugzilla, a blank view when the hardware
  acceleration policy is set to `NEVER` after the first load, new in 2.54.
- `tauri-linux-graphics.md`: Tauri (documentation and wry), the workaround that reverses in
  WebKitGTK 2.54 and the missing hook to configure the web view before it loads.
